# Beginner AI/ML Portfolio

Three beginner-level Python and Streamlit prototypes built
to practise programming, rule-based logic, and user interface
development.

## Projects

### 1. Medical Interpreter Accuracy Checker
Flags configured phrases that appear in an original statement
but are missing from a back-translated statement.

### 2. Herbal Medicine Interaction Checker
Demonstrates a lookup interface for a small, incomplete
herb–medicine reference dataset.

### 3. Medical Device Conflict Detector
Demonstrates checking fictional device configurations against
predefined example rules.

## Technologies
- Python
- Streamlit
- Git and GitHub

## Run a project
Open the desired project folder, activate its Python virtual
environment, and run:

    streamlit run app.py

Install Streamlit first if needed:

    pip install streamlit

## Limitations
These are educational prototypes, not validated AI models,
clinical decision tools, interaction databases, or medical
device safety systems. Their outputs must not be used to make
medical decisions.
